# Polish is mostly state design

A finished interface is not the one with the most decoration. It is the one that answers what happened, what is happening, and what can happen next.

## Name the states

Loading, empty, error, disabled, saved, and unsaved should not be afterthoughts. Each state is part of the product's language.

## Motion should preserve context

A transition is useful when it explains where something went. Reduced motion should keep the same meaning without asking the device to animate.

## Conclusion

The last ten percent is often a better sentence, a clearer focus ring, or one fewer shadow.
