# Overview

Starship Simulation is an interface experiment about making a complex system feel inspectable rather than intimidating.

## Focus

The current prototype explores spatial relationships, event streams, and the small decisions that change a route. It is not published yet; this file stays visible in the admin workspace as a reminder that unfinished work can still have a clear shape.

## Next step

The next iteration will test whether the simulation can explain cause and effect without asking the operator to read every event.
