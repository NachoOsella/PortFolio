# About me

I am Ignacio Osella, a backend developer from Córdoba, Argentina. I specialize in Java and Spring Boot, with a focus on REST APIs, application security, relational persistence, and modular architectures that remain understandable as a product grows.

I am most comfortable on the backend, but I work across the whole path to production. I have built Angular interfaces with standalone components and Signals, PostgreSQL schemas and Flyway migrations, multi-service Docker Compose environments, and Nginx deployments. Knowing the full system helps me make better backend decisions.

## What I am looking for

I am looking for a backend opportunity where I can contribute with Java and Spring Boot, learn from experienced engineers, and help build reliable, maintainable, high-performance software. I care about clear domain boundaries, predictable behavior, and code the next person can understand without archaeology.

## Experience

Since 2024, I have designed personal and academic systems around clean architecture and domain-oriented modules. My work includes:

- REST APIs with Spring Boot, Spring Security, JWT, BCrypt, OpenAPI, and stateless sessions.
- Relational models with JPA/Hibernate, PostgreSQL, MySQL, and versioned Flyway migrations.
- Automated tests with JUnit 5, Mockito, Testcontainers, and Vitest.
- Angular applications using standalone components, Signals, PrimeNG, Tailwind CSS, guards, and interceptors.
- LLM integration through Spring AI and Groq/Llama 3.3, with structured output validated before persistence.
- Collaborative academic development with Scrum, feature branches, pull requests, and code review.

My main project is **Dietetica Lembas**, a thesis system that unifies commercial management and e-commerce for a real health food store. It includes lot-based FEFO inventory, POS and online sales, cash reconciliation, Mercado Pago, JWT authorization, and a Dockerized Java/Angular/PostgreSQL stack.

I also built **PlanAI**, an AI-assisted planning tool; **java-logic-trainer.nvim**, a Neovim plugin with more than 187 test-driven Java exercises; **Gruvboxitator**, a local browser image-processing pipeline; and this Markdown-first portfolio.
