# Uses

The tools I use daily and the defaults behind the projects on this site.

## Editor and terminal

**Neovim** is my main editor. I maintain my own configuration and wrote **java-logic-trainer.nvim**, so the editor is also a place where I experiment with Lua, async jobs, quickfix integration, and developer-tool UX.

I use a keyboard-first terminal workflow with Git and the GitHub CLI. The visual theme is usually Gruvbox Material Dark Hard — consistently enough that I built Gruvboxitator to process images into the same palette.

## System

Linux, currently Arch-based, with versioned dotfiles on GitHub. I prefer understanding and keeping the configuration that shapes my development environment rather than treating it as an opaque setup script.

## Backend

Java 21, Spring Boot, Spring Security, Spring Data JPA/Hibernate, Bean Validation, OpenAPI, Flyway, Maven, PostgreSQL, and MySQL. For AI-integrated work: Spring AI with Groq/Llama.

## Frontend

Angular 21 with standalone components and Signals for application work. React 19, TypeScript, and Vite for focused tools and this portfolio. PrimeNG, Tailwind CSS, and shadcn/ui when they solve a concrete interface need.

## Testing and delivery

JUnit 5, Mockito, Testcontainers, Vitest, Docker, Docker Compose, Nginx, and Caddy. I use real PostgreSQL containers for integration boundaries instead of assuming an in-memory database behaves the same.

## Thinking and collaboration

Markdown notes, architecture decision records, diagrams before abstractions, small pull requests, and commit messages that explain intent. For team projects: Scrum, feature branches, pull requests, and code review.
